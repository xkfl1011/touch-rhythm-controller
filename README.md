# 작동 방식

라즈베리 파이를 usb입력 장치로 설정(라즈베리 파이 5 기준)
터치 디스플레이와 라즈베리 파이, 라즈베리 파이와 PC를 연결
터치 디스플레이를 터치
터치이벤트를 라즈베리 파이에 전달
라즈베리 파이가 그 정보를 PC에 전달
PC는 그 정보를 각각 해당하는 키 입력으로 인식
